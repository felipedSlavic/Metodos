# Métodos - Java☕📦

Exercícios de lógica de programação em java com vetores.
<br>
Desenvolvidos durante o 2º semestre de Sistemas de Informação na FIAP.

## Exercícios
exercicio01 — sistema de pousada: diárias com método de cálculo <br>
exercicio2 — transportadora: cálculo de frete por caminhão <br>
exercicio03 — vazio (esqueleto) <br>
exercicio04 — sistema de chamados com verificação de erros e critérios <br>
exercicio05 — ordenação de vetor com método separado (marcado pra revisar) <br>
exercicio06 — vendas de 4 produtos com meta, matriz de vendas e relatório <br>
Exercicio07 — estoque de 5 modelos de carro (Classic, Cobalt, Onix…) com preços <br>
Exercicio08 — relatório gerencial de pilotos de F1 por país
